# Security policy

Central security policy for [firelilydancingpenguin](https://github.com/firelilydancingpenguin)
repositories.

## Reporting a vulnerability

Report a vulnerability privately through this repository's **private
vulnerability reporting** (Security -> Report a vulnerability), or through
the same feature on the affected repository when it has it enabled. Never
open a public issue for it.

Include the affected repository and path, how to reproduce, and the impact
you observed. Expect an acknowledgement within 5 working days.
